# Backlog

O backlog completo do MVP está rastreado no Jira, projeto **PROJ**, board Scrum:
https://ruaancarlos2602.atlassian.net/jira/software/projects/PROJ/boards/35/backlog

**Estrutura:**
- **14 épicos** (`PROJ-1` a `PROJ-14`) — um por módulo/pilar do produto.
- **13 sprints** (Sprint 0 a Sprint 12, 2 semanas cada) — cada um com uma tarefa-container vinculada ao épico correspondente.
- **59 itens de trabalho** (subtarefas) — o detalhamento executável de cada sprint, rastreável individualmente.

A versão legível e versionada em texto desse mesmo backlog está em [`../docs/07-roadmap/backlog-sprints.md`](../docs/07-roadmap/backlog-sprints.md) — mantida em paralelo ao Jira como documentação de referência do repositório, para quem não tem acesso ao board.
